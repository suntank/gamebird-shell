Optional PlayStation BIOS files belong in this directory. Over Samba, this is
the GameBird/roms/psx/bios folder.

PCSX-ReARMed will run without one by using its open HLE BIOS, but an authentic
BIOS dumped from hardware you own improves game compatibility. Common supported
names include scph5501.bin, scph7001.bin, scph1001.bin, and scph101.bin.

GameBird does not include or provide Sony BIOS files.
